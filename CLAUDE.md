# ClemicheLabs – Portfolio Website

> Single-page Flutter Web app with Firebase Hosting + Firestore contact form.

---

## Tech Stack

**Flutter 3.11+ / Dart 3.11+ / Firebase (Core, Firestore) / Riverpod 3 / Freezed / flutter_animate**

No routing library — single-page scroll site with `ScrollController` + `GlobalKey` anchors.

---

## Architecture

```
lib/
├── main.dart                  # Firebase init, ProviderScope
├── firebase_options.dart      # Generated by flutterfire configure
├── core/
│   ├── theme/app_theme.dart   # Design system (colors, typo, helpers)
│   ├── constants/content.dart # All marketing copy & project data
│   └── utils/responsive.dart  # Breakpoint helpers
├── domain/
│   └── contact/               # Freezed model for form submissions
├── application/
│   ├── theme/                 # Dark/light toggle provider
│   ├── scroll/                # Active section tracking
│   └── contact/               # Contact form state + Firestore write
└── presentation/
    ├── app.dart               # MaterialApp with theme provider
    ├── home/home_screen.dart  # Scaffold + scroll + all sections
    ├── sections/              # hero, services, portfolio, about, process, testimonials, contact
    └── shared/widgets/        # nav_bar, section_wrapper, cards, footer, neon_button
```

### Data Flow

```
UI (ConsumerWidget) → Provider → Notifier → Firestore
```

No service layer, no Either pattern — direct Firestore calls in notifiers (portfolio site simplicity).

## Design System

| Token | Value | Usage |
|-------|-------|-------|
| `AppTheme.primary` | `#00f2ff` | CTAs, accents, glow |
| `AppTheme.backgroundDark` | `#0f2223` | Dark mode bg |
| `AppTheme.backgroundLight` | `#f5f8f8` | Light mode bg |
| `AppTheme.cardDark` | `#162e2f` | Card surfaces |
| `AppTheme.textMuted` | `#8ba8a9` | Secondary text |
| Font | Space Grotesk | All text via google_fonts |
| Radii | sm(8) md(16) lg(32) full(9999) | Consistent rounding |

Always use `AppTheme.*` constants. Never hardcode colors or radii.

---

## Code Rules

- Explicit types on all variables, parameters, and return types
- `const` constructors everywhere possible
- Single quotes, trailing commas, package imports
- Extract widgets — never use `_buildX()` helper methods
- `AppContent.*` for all marketing copy (never inline strings)
- Responsive: use `Responsive.*` helpers, never raw `MediaQuery`
- Keep files ~200 lines; extract when larger

## Development Commands

```bash
# Dependencies
flutter pub get

# Code generation (after changing @freezed or @riverpod)
dart run build_runner build --delete-conflicting-outputs

# Analysis
flutter analyze

# Run (web only)
flutter run -d chrome

# Build for deploy
flutter build web

# Deploy
firebase deploy --only hosting
```

## Firebase

- **Project:** clemichelabs
- **Hosting:** `build/web`, SPA rewrite
- **Firestore:** `contact_submissions` collection (anonymous create only)
- **Rules:** `firestore.rules` — validates name/email/message fields
